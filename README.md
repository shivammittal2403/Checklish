# Security Checklist Library

Professional static portal generated from 17 cybersecurity assessment workbooks.

## Coverage

- 17 source checklists
- 30 workbook sheets
- 1,248 populated checklist items
- Search, category filters, sheet navigation, and browser-local review progress

## Run locally

Serve the repository root with any static web server.

```powershell
python -m http.server 4180
```

## Data note

Workbook content is presented as provided. Validate technical procedures before use and operate only with explicit authorization.
