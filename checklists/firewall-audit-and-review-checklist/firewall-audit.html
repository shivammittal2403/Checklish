020

Proxy ARP

Row 22
Sr. No
20
Audit Methodology
Confirm that Proxy ARP is not enabled. ARP is a protocol that network hosts use to translate network IP addresses into MAC (Media Access Control) addresses. When a firewall has Proxy ARP enabled, the firewall answers ARP requests intended for another device. By "faking" its identity, the firewall accepts responsibility for routing packets to the real destination. Proxy ARP can however be exploited to effect ARP redirection. This can be used to: Undertake a denial of service attack that uses bandwidth and switch resources responding to repeated ARP requests Reduce the likelihood of spoofed ARP requests from being detected. NB: The use of Proxy ARP on a firewall is unusual. Proxy ARP is normally implemented on switches and routers.
