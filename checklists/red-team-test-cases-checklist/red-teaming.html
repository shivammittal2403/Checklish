001

Scoping

Row 3
Sr. No
1
Activity
Giving a wide scenario here - In my previous work client came to us and said this is our company name and here is the list of all 30 acquisitions of us. The client wanted to perform Red Team assessment in two phase: In phase 1, Client asked us to just find (not to test) the entire scope reachable from the public internet such as domain, IP, website, subdomain, exposed services to the Internet, mail exchange servers, VPN servers, security devices, DNS servers etc. The client wanted to just confirm the entire scope if that is applicable to their organization or not. Once scoping review is done from client's end, they will provide the final list of application scope for us to go ahead and start pentesting for it. I have added few sample test cases on the 'How to test' section:
Resources
- Look for company website. - Look for sub-domains using dns dumpster, fierce, knock.py tools. - Google dork - site:*.site.com - Use OSINT tool - Datasploit to find list of domains, IPs, leaked info etc. - Query WHOIS - Query DNS - Perform zone transfer to find additional domains - Use theHarvester.py python script - Use maltego for each domain/IP/app server/MX server/DNS server/VPN service/Remote access service etc. - Use shodan search engine and query client's name in the search input field. - Search client's keyword in darknet/deepweb search engine. - Use spiderfoot - Use amass for subdomain enumeration from 23 different data sources (https://github.com/caffix/amass/releases/tag/v1.5.1)
